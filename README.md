# ORE — Open Roleplay Engine

**Русский** | [English](README.en.md)

**Скачать:** откройте страницу [Releases](https://github.com/olegpro171/Roleplay-Engine/releases) и скачайте установщик/лаунчер для своей операционной системы. Следуйте инструкциям для вашей операционной системы.

ORE — приложение для ролевого общения с ИИ на вашем компьютере. В центре внимания — простота, настройка промптов и долговременная память. Приложение открывается в браузере; при желании к нему можно подключиться с телефона в той же локальной сети.

**Статус:** Проект готов к первому бета-тестированию. Проверяется качество памяти и работа на разных платформах и устройствах.

## От автора

Зачем еще одно приложение для общения с ИИ? Ответ: мне хотелось простое приложение, которое сочетает встроенную память, простоту в настройке и детальную настройку промпта. Я не нашел проекта, который бы закрывал эти потребности без компромисов, поэтому я создал свой. В первую очередь это мой проект для души.

Не буду делать вид, что я не полагался на ИИ-разработку. Скажу прямо: большую часть кода приложения я даже не читал.

Однако, я имею высокую планку качества интерфейса и удобства использования, поэтому многократно проверял удобство различных сценациев использования и тчательно доводил интерфейс до финального состояния. Я не могу гарантировать того, что в приложении не осталось шероховатостей, поэтому буду рад любой обратной связи.

Главный принцип этого проекта заключается в простоте: если функция не необходима для обеспечения удобства пользователя или качества ответов ИИ, я предпочту её не добавлять.

В текущие планы не входят голосовые звонки, озвучка текста, музыкальные плееры, управление фонами или анимированные спрайты в стиле визуальных новелл. Мой приоритет — это сделать основные функции удобными и надёжными.

## Что здесь есть

- Импорт персонажей из JSON/PNG V1/V2/V3.
- Лорбуки.
- Редактор промптов.
- Многоуровневая нарративная память: вокруг чего проект и разрабатывался.
- Подключения к эндпоинтам Chat Completions (на данный момент доступны только OpenAI-compatible).
- Интерфейс для компьютера и телефона
- Темная и светлая тема
- Русский/английский языки интерфейса.
- Резервное копирование данных и средства восстановления.
- (Очевидно) отсутсвует сбор аналитики и телеметрии.

Поддержка карточек персонажей ограничена определённым набором возможностей.

## Многоуровневая нарративная память

Долгая переписка рано или поздно перестаёт помещаться в окно ввода модели. ORE сохраняет недавние ходы дословно, объединяет старые ходы в сводки и, по мере роста числа сообщений, сжимает группы сводок.

Вы управляете размером вводаб после которого применяется сжатие; минимальным объёмом дословной недавней истории, размерами групп и промптами для сводок. Можно просматривать уровни и текст исходной переписки, редактировать неточности в сводках.

Разумеется, эта система может гарантировать идеальную память лишь настолько, насколько ИИ-модель способна извлечь факты из текста, и насколько она способна сжимать предыдущие сводки, сохранаяя значимые факты и отбрасывая лишние детали.

## Установка

Вам нужен компьютер, браузер и доступ к провайдеру модели.

### Лаунчер для Windows

Скрипт установки находится в файле [ORE-launcher.bat](ORE-launcher.bat).

Поместите этот файл в папку где Вы хотите установить ORE и запустите двойным щелчком.

Скрипт установит ORE в папку `ORE-internal/`. При первой установке скачивается последний исходный код ветки `main` и изолированный набор инструментов, затем ORE собирается, проверяется и запускается.

Поддерживается платформа Windows x64 со встроенными 64-разрядными Windows PowerShell 5.1/.NET.

### Лаунчер для macOS

Скрипт установки находится в файле [ORE-launcher.command](ORE-launcher.command).

Поместите этот файл в папку где Вы хотите установить ORE.

Скрипт обычно скачивается без права на выполнение. Перед первым запуском откройте Терминал и выдайте право на запуск скачанному файлу:

```sh
chmod u+x "/путь/до/ORE-launcher.command"
```

> Чтобы не прописывать путь вручную, напишите в терминале `chmod u+x ` (с пробелом на конце), а затем перетащите в терминал скачанный скрипт, путь заполнится автоматически.

После этого, запустите скрипт двойным щелчком.

Если macOS блокирует скачанный файл, воспользуйтесь отдельным разрешением для этого файла в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

Скрипт установит ORE в папку `ORE-internal/`. При первой установке скачивается последний исходный код ветки `main` и изолированный набор инструментов, затем ORE собирается, проверяется и запускается.

Поддерживается платформа macOS 13.5+ на arm64/x64.


## Первый чат

1. После запуска сервера, перейдите по указанному адресу.
2. Создайте пароль владельца.
3. Для смены языка выберите **Settings → Interface language**
4. В разделе **Библиотека → Подключения** импортируйте или создайте новое подключение.
5. Создайте или импортируйте персонажа и персону, затем откройте **Библиотека → Чаты → Новый чат**.
6. Проверьте выбранные настройки, затем сохраните.

Вы также можете продолжить существующую историю. Для этого импортируйте файл `.jsonl` в формате SillyTavern через настройки чата, проверьте количество сообщений и подтвердите **Заменить все сообщения**. Это заменяет историю и память выбранного чата: используйте новый или ненужный чат.

## Доступ с телефона

Включите **Настройки → Телефон / локальная сеть** на компьютере с сервером. Откройте показанный адрес на телефоне в той же локальной сети. Компьютер должен оставаться включённым и не переходить в сон.

Закрытие вкладки на телефоне или потеря соединения не отменяют генерацию.

## Данные и резервные копии

Приложение хранит содержимое чатов, данные о персонажах, API-ключи и т.д. локально на компьютере с сервером.

Используется база данных `ORE-internal/data/roleplay.sqlite`, конфигурация находится в `ORE-internal/.env`.

Содержимое запросов отправляется на настроенный вами эндпоинт модели; к нему применяются правила конфиденциальности этого сервиса.

## Разработка

Перед изменениями приложения прочитайте [AGENTS.md](AGENTS.md), [контракт продукта](CONCEPTS.md) и [руководство по архитектуре и разработке](IMPLEMENTATION.md). Эти документы ссылаются на подробные контракты подсистем. В текущих условиях отдельный процесс участия в разработке или подачи отчётов не требуется.


```sh
npm run build     # Проверка типов и сборка
npm test          # Тесты ядра, сервера и хранилища
npm run test:e2e  # Браузерные сценарии; сначала выполните сборку
npm run check    # Сборка и оба набора тестов
```

Для браузерных тестов нужны `npx playwright install chromium webkit` и разрешение запускать локальные серверы. WebKit используется для проверки сохранения прокрутки при выборе записей лорбука в движке Safari. Тесты используют временные данные и имитацию провайдеров.
