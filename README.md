# ORE — Open Roleplay Engine

**Русский** | [English](README.en.md)

**Скачать для Windows x64.** Файл `ORE-launcher.bat` доступен на странице [Releases](https://github.com/olegpro171/Open-Roleplay-Engine/releases).

ORE — приложение для ролевого общения с ИИ на вашем компьютере. В центре внимания — простота, детальная настройка промптов и долговременная память. Приложение открывается в браузере; при желании к нему можно подключиться с телефона в той же локальной сети.

## От автора

Зачем еще одно приложение для общения с ИИ? Ответ: мне хотелось простое приложение, которое сочетает встроенную память, простоту и детальную настройку промпта. Я не нашел проекта, который бы закрывал эти потребности без компромисов, поэтому я создал свой. В первую очередь это мой проект для души.

Не буду делать вид, что я не полагался на ИИ-разработку. Скажу прямо: большую часть кода приложения я даже не читал.

Однако, я имею высокую планку качества интерфейса и удобства использования, поэтому многократно проверял удобство различных сценациев использования и тчательно доводил интерфейс до финального состояния.

Приложение все еще в активной разрабоке, поэтому, на данном этапе, я не могу гарантировать того, что в приложении не осталось шероховатостей. Однако, именно это является моей конечной целью. Я буду рад любой обратной связи.

Главный принцип этого проекта заключается в простоте: если функция не необходима для обеспечения удобства пользователя или качества ответов ИИ, я предпочту её не добавлять.

В текущие планы не входят голосовые звонки, озвучка текста, музыкальные плееры, управление фонами или анимированные спрайты в стиле визуальных новелл. Мой приоритет — это сделать основные функции удобными и надёжными.

## Что здесь есть

- Импорт персонажей из JSON/PNG V1/V2/V3.
- Лорбуки.
- Редактор промптов.
- Многоуровневая нарративная память: вокруг чего проект и разрабатывался.
- Подключения к эндпоинтам Chat Completions (на данный момент доступны только OpenAI-compatible).
- Интерфейс для компьютера и телефона
- Темная и светлая тема
- Русский/английский языки интерфейса.
- Резервное копирование данных и средства восстановления.
- (Очевидно) отсутсвует сбор аналитики и телеметрии.

## Многоуровневая нарративная память

Долгая переписка рано или поздно перестаёт помещаться в окно ввода модели. ORE сохраняет недавние ходы дословно, объединяет старые ходы в сводки и, по мере роста числа сообщений, сжимает группы сводок.

Вы управляете размером ввода, после которого применяется сжатие; минимальным объёмом дословной недавней истории, размерами групп и промптами для сводок. Можно просматривать уровни и текст исходной переписки, редактировать неточности в сводках.

Разумеется, эта система может гарантировать идеальную память лишь настолько, насколько ИИ-модель способна извлечь факты из текста, и насколько она способна сжимать предыдущие сводки, сохранаяя значимые факты и отбрасывая лишние детали.

## Установка

Вам нужен компьютер, браузер и доступ к провайдеру модели.

### Лаунчер для Windows

Скрипт установки находится в файле `ORE-launcher.bat`. Загрузите его со страницы [Releases](https://github.com/olegpro171/Open-Roleplay-Engine/releases).

Поместите этот файл в папку где Вы хотите установить ORE и запустите двойным щелчком.

Скрипт скачает последний опубликованный пакет для Windows, проверит его, установит в папку `ORE-internal/` и запустит ORE. Используйте тот же лаунчер для следующих запусков и обновлений. Если обновление не удастся скачать, запустится установленная версия.

Если старый лаунчер не обновляет ORE, остановите приложение, замените `ORE-launcher.bat` рядом с существующей папкой `ORE-internal/` и запустите его двойным щелчком. Сохраните папку `ORE-internal/` с данными и настройками.

Для Windows x64 используются встроенные 64-разрядные Windows PowerShell 5.1 и .NET. Порядок восстановления описан в разделе [о прежних установках](docs/RELEASES.md#legacy-installations).

### Запуск из исходного кода на macOS

В каталоге репозитория запустите `./start-dev.command`. Скрипт собирает текущий рабочий каталог в `ore-development/`. Подробности приведены в [руководстве по запуску из исходного кода](docs/RELEASES.md#working-tree-development).

## Первый чат

1. После запуска сервера, перейдите по указанному адресу.
2. Создайте пароль владельца.
3. Для смены языка выберите **Settings → Interface language**
4. В разделе **Библиотека → Подключения** импортируйте или создайте новое подключение.
5. Создайте или импортируйте персонажа и персону.
6. Создайте новый чат: **Библиотека → Чаты → Новый чат**, или импортируйте уже имеющийся в формате Sillytavern JSONL.
7. Проверьте выбранные настройки, затем сохраните.


## Доступ с телефона

Включите **Настройки → Телефон / локальная сеть** на компьютере с сервером. Откройте рекомендуемый адрес по имени компьютера на телефоне в той же локальной сети. Если он не работает, попробуйте показанный рядом адрес локального IPv4; он доступен и при ошибке определения имени компьютера. При смене адреса может понадобиться войти снова. IPv4 может измениться — актуальный адрес указан в настройках. Компьютер должен оставаться включённым и не переходить в сон.

## Данные и резервные копии

Приложение хранит содержимое чатов, данные о персонажах, API-ключи и т.д. локально на компьютере с сервером.

Установки из пакета Windows используют `ORE-internal/data/roleplay.sqlite` и `ORE-internal/.env`. При запуске из исходного кода используются `data/roleplay.sqlite` и `.env` в каталоге репозитория.

Содержимое запросов отправляется на настроенный вами эндпоинт модели; к нему применяются правила конфиденциальности этого сервиса.

## Перенос ORE в другую папку на Windows

ORE можно перенести в другую папку. Чаты, настройки и остальные данные переместятся вместе с папкой `ORE-internal/`.

1. Сохраните резервную копию через **Настройки → Резервное копирование** за пределами папки установки. Нажмите **Ctrl+C** в окне лаунчера и дождитесь остановки ORE.
2. Переместите `ORE-launcher.bat` и папку `ORE-internal/` в локальную папку с правом записи, где ещё нет другой установки ORE. Оставьте файл лаунчера рядом с папкой `ORE-internal/` и сохраните её имя.
3. Запустите `ORE-launcher.bat` из новой папки и проверьте, что сохранённые чаты открываются.

## Удаление ORE

1. Чтобы сохранить чаты, память, библиотеки и подключения, создайте резервную копию в разделе **Настройки → Резервное копирование** и сохраните её за пределами папки `ORE-internal/`. Если хотите сохранить свои языковые пакеты, скопируйте их отдельно: они не входят в резервную копию. См. [что входит в резервную копию](docs/DATA.md#content-backups).
2. Нажмите **Ctrl+C** в терминале или окне лаунчера, где запущен ORE, и дождитесь остановки. Закрытие вкладки браузера не останавливает сервер.
3. **Windows:** Удалите лаунчер `ORE-launcher.bat` и папку `ORE-internal/`. Вместе с ними удалятся все данные приложения. **macOS при запуске из исходного кода:** Удалите папку репозитория. Чтобы удалить только сборку, созданную `./start-dev.command`, удалите `ore-development/`.

**Временные файлы:** Если работа лаунчера Windows была прервана, в %TEMP% могут остаться папки ore-types-*. После остановки ORE эти папки можно удалить вручную.

Некоторые данные, такие как черновики, некоторые настройки и файлы cookie, сохраняются в браузере на устройстве, с которого вы использовали ORE. Чтобы удалить их очистите данные сайта для адреса ORE на каждом устройстве.

## Разработка

Перед изменениями приложения прочитайте [AGENTS.md](AGENTS.md), [контракт продукта](CONCEPTS.md) и [руководство по архитектуре и разработке](IMPLEMENTATION.md). Эти документы ссылаются на подробные контракты подсистем. В текущих условиях отдельный процесс участия в разработке или подачи отчётов не требуется.


Для разработки из исходного кода используйте Node 24 или Node 22.14+ в пределах основной версии 22.

```sh
npm run build     # Проверка типов и сборка
npm test          # Тесты ядра, сервера и хранилища
npm run test:e2e  # Браузерные сценарии; сначала выполните сборку
npm run check    # Сборка и оба набора тестов
```

Для браузерных тестов нужны `npx playwright install chromium webkit` и разрешение запускать локальные серверы. WebKit используется для проверки сохранения прокрутки при выборе записей лорбука в движке Safari. Тесты используют временные данные и имитацию провайдеров.
